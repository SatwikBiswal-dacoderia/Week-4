# Week 4 – Python Dictionary Projects 🐍

This repository contains my Week 4 Python practice projects as a first-year Artificial Intelligence and Machine Learning (AIML) student. These projects focus on dictionaries, user input, data storage, calculations, and conditional logic.

## 📂 Projects

### 1. Fruit Price Dictionary
Takes the names of three fruits and their prices as user input, stores them in a dictionary, and prints the dictionary.

**Concepts Practised:**
- Dictionaries
- User input
- Key-value pairs
- Storing and displaying data

### 2. Personal Information Dictionary
Takes personal information such as name, age, and city from the user, stores it in a dictionary, and prints the city value.

**Concepts Practised:**
- Dictionaries
- User input
- Accessing values using keys
- Key-value pairs

### 3. Marks Calculator and Grading System
Takes subject names and marks as user input, stores them in a dictionary, calculates total marks and percentage, and determines the grade based on the percentage.

**Concepts Practised:**
- Dictionaries
- User input
- Loops
- Numeric operations
- Calculating total marks and percentage
- Conditional statements (`if`, `elif`, `else`)
- Grade determination

### 4. Character Frequency Counter
Takes a word from the user and creates a dictionary that counts how many times each character appears.

**Concepts Practised:**
- Dictionaries
- Strings
- Loops
- Character frequency counting
- Updating dictionary values

## 🛠️ Technologies Used

- Python 3
- VS Code or another Python-compatible editor

## ▶️ How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run a Python file using:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the actual name of the Python file you want to run.
